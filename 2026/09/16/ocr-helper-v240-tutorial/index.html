1. 这个软件能帮你做什么

OCR 助手是一款 Windows 桌面小工具。一句话概括:

你在屏幕上看到什么,它就帮你认字、答题、翻译——不用复制、不用截图保存、不用来回切窗口。

它主要解决三类场景:

场景 你会怎么用它
在线答题 / 题库练习 把透明”洞口”对准题目,按一下快捷键,答案直接显示在窗口里
看外文资料 / 影视字幕 拖框选中一段外文,点”翻译此区域”,下方直接给出中文译文
把屏幕上的文字变成可复制文本 框选任意区域,识别结果可以一键复制到剪贴板

它有两种”大脑”,你可以随时切换:

  • 云端:调用你配置的 AI 平台(如阿里云百炼、DeepSeek、智谱等),识别准、答题强、翻译好,但需要联网、消耗你的 API 额度;
  • 端侧(本地):模型跑在你自己的电脑上,完全离线、不花钱,代价是准确度和速度不如云端。

重要提醒:软件本身不上传你的截图到任何地方,图片只会发送给你自己配置的 AI 平台(云端模式时)。所有配置、Key、历史都只保存在你电脑上。

2. v1.0.0 到 v2.4.0:这一版变了什么

如果你用过 v1.0.0,下面这张表能让你快速上手新界面:

方面 v1.0.0 v2.4.0
界面技术 Python(PySide6)绘制 React + Tailwind CSS(外观更现代,主题可换)
模式 只有透明悬浮窗 四种模式:悬浮窗 / 翻译 / 自由截图 / 迷你条
洞口 透明但鼠标点不进去 洞内鼠标可直接穿透,能点后方内容(一边看题一边作答)
翻译 无 翻译模式:双语对照、语言方向可选、可自动刷新
本地模型 内置在安装包里 按需下载、分三档(轻量/均衡/全量),体积可控
窗口缩放 只能输入宽高 拖四边/四角缩放;缩太小自动转迷你条
主题 黑/白/灰 5 套预设 + 自定义配色,可导入导出
提问 单行输入框 多行大输入框 + 示例提问下拉 + 自输入自动记住
开机速度 较快 首次启动需解压数秒(单文件打包的代价)
开源协议 MIT CC BY-NC 4.0(禁止商业使用,转载须注明出处)

3. 准备工作:三种使用方式,你该选哪种

方式 适合谁 需要装 Python? 难度
打包版 exe 99% 的用户 不需要 简单
源码运行 想改代码 / 想用端侧模型高级档 需要 中等
二次开发前端 想改界面(React) 需要 Node.js 较难

大多数情况请选打包版。以下系统要求三种方式相同:

  • Windows 10 / 11(64 位);
  • 支持多显示器与 100% / 125% / 150% / 200% 缩放(程序已做 DPI 适配);
  • 云端模式需要能访问你选择的 AI 平台;端侧模式可完全离线。

6. 第一次识别:5 分钟跑通全流程

前提:先在「设置 → 模型设置」里填好 API Key(见第 10 章)。如果还没填,程序会在状态栏提示”未配置 API Key”。

第 1 步:启动程序,你会看到一个浮在屏幕上的小窗口(悬浮窗模式)。

第 2 步:对准目标——按住窗口的顶部图标栏或底部状态栏拖动,让中间的红框”洞口”套住你要看的内容。

为什么必须拖顶部/底部?因为洞内是鼠标穿透的:点洞里等于点后面的网页,方便你一边看题一边作答。所以洞里不能用来拖动窗口。

第 3 步:填写提问(可选)——底部多行输入框里可以写你要它做什么,例如:

  • 请回答识别到的内容(默认)
  • 请翻译识别到的内容
  • 请解释识别到的内容
  • 请搜索并告诉我相关联的内容

点输入框右侧的列表图标可以看到更多示例;你自己输入过的提问会被自动记住,下次可以直接从列表里选。

第 4 步:点「识别」按钮,或按快捷键 Ctrl+F1。

第 5 步:看结果——窗口底部会出现两个可折叠区块:

  • 识别结果:OCR 认出来的文字;
  • 回答:AI 给出的答案/译文/解释。

状态栏上的小标签会显示题型、来源(云端模型/端侧模型/本地知识库)、OCR 耗时与回答耗时。

[图片说明:此位置为识别完成界面,操作为指出【识别结果】【回答】两个区块与状态栏标签]

第 6 步:后续操作

  • 点复制图标把回答复制到剪贴板;
  • 点垃圾桶图标清空结果;
  • 想换一个区域:点框选图标重新选择;
  • 想改洞口尺寸:底部两个数字输入框里填宽 × 高,或者直接拖窗口边缘。

7. 第一次翻译:翻译模式怎么用

翻译模式和悬浮窗模式不一样:它没有中间那个透明洞口,而是把”识别原文”和”译文”两块放大显示,适合看资料、看字幕。

7.1 进入翻译模式

在顶部模式切换器里点「翻译」(当前模式会展开文字,未选中的只显示图标)。

[图片说明:此位置为顶部模式切换器,操作为点击”翻译”图标]

7.2 选好语言方向

顶部第二行有 [来源语言] ⇄ [目标语言] 两个下拉框:

  • 来源语言可以选「自动检测」(不确定时就用它),也可以明确指定(如「英语」);
  • 点中间的双向箭头图标可以一键互换;
  • 这个选择会真的写进发给模型的指令里,所以一定要选对,否则翻译方向会错。

7.3 第一次翻译:先框选一次

  1. 点「框选新区域」按钮(或按 Ctrl+Shift+A);
  2. 屏幕变暗,按住鼠标左键拖出一个矩形,把要翻译的内容框住;
  3. 松开鼠标后,操作条里有三个按钮:
    • 识别:只识别不翻译;
    • 翻译此区域:直接翻译,并进入翻译模式;
    • 设为悬浮窗区域:把这个选区变成悬浮窗的洞口;
    • 取消:退出框选(也可按 Esc)。

操作条里还内嵌了「识别 云端/本地」「翻译 云端/本地」两个开关、语言方向和提问输入框——框选前就能一次设定好,不用来回切设置。

7.4 之后每次只用点一个按钮

翻译模式会记住你上次框选的区域。以后只要点「捕获并翻译」,它就会重新截取同一块区域并翻译——内容更新了,位置不用重选。这对看视频字幕、盯着同一块网页特别方便。

7.5 双语对照 / 仅译文

顶部有显示方式切换:

  • 双语对照(默认):原文完整显示在上方,译文显示在下方,一段一段对照,没有多余的框线和分隔符;
  • 仅译文:只显示译文,适合只看结果。

7.6 自动刷新(看字幕用)

点顶部那个循环箭头图标开启「自动刷新」,程序会按设定间隔(默认 2.5 秒,可在设置里改)自动重新捕获并翻译。适合视频字幕、直播画面这类持续变化的内容。

7.7 关于翻译质量,你需要知道的

引擎 质量 速度 花费
云端翻译(推荐) 最好,长句、专业词、从句都稳 1-5 秒 消耗 API 额度
端侧·轻量档(opus-mt) 能看懂大意,长句和术语较弱 每段 0.03-0.1 秒 免费、离线
端侧·均衡档(NLLB-600M) 明显更好,可用水平 每段约 3-4 秒(CPU) 免费、离线
端侧·全量档(NLLB-1.3B) 端侧最高 每段约 2-10 秒(CPU) 免费、离线

结论:日常追求质量就用云端;需要离线、不想花钱就用端侧的均衡或全量档。

8. 四种模式详解与切换

模式 长什么样 最适合 切换方式
悬浮窗模式 中间一个透明洞口,上下是操作面板 反复识别同一片区域(如在线答题) 点图标 / Ctrl+1
翻译模式 无洞口,原文与译文两大块 看外文资料、字幕 顶部切换器
自由截图模式 全屏变暗,拖框选区 临时框选任意位置 Ctrl+Shift+A 或 Ctrl+3
迷你条模式 一条极简图标工具条 + 提问输入行 不想遮挡画面,随手识别 点图标 / Ctrl+2

迷你条特性:首次进入会自动居中停靠在任务栏上方,可以自由拖动;点最左边的识别图标会复用上次选区直接识别(没有选区时会进入框选)。

窗口缩放与模式自动切换(v2.4.0 新增):

  • 拖窗口四边或四角可改变大小;
  • 悬浮窗缩到小于 420×300 时,会自动切换成迷你条;
  • 迷你条拖宽超过 560 时,会自动切回悬浮窗。

全局快捷键(可在设置里修改):

快捷键 作用
Ctrl+F1 识别(悬浮窗模式)/ 进入框选(迷你条模式)
Ctrl+Shift+A 进入自由截图模式
Ctrl+1 / Ctrl+2 / Ctrl+3 切换 悬浮窗 / 迷你条 / 自由截图
Ctrl+Q 退出程序

10. 配置你的 AI 平台(必做)

云端模式必须填 API Key。以阿里云百炼为例(其他平台类似):

  1. 打开 https://bailian.console.aliyun.com/ 注册并登录;
  2. 在控制台里开通模型服务,并创建一个 API Key(通常形如 sk-xxxxxxxx);
  3. 记下你要用的模型 ID,例如 qwen3.7-flash-2026-07-15;
  4. 回到软件:点齿轮打开设置 → 模型设置;
  5. 在左侧平台列表里选中「阿里云百炼」;
  6. 右侧依次填写:
    • API Key:粘贴刚才的 Key(输入框右侧的眼睛图标可切换明文/密文);
    • 模型 ID:粘贴第 3 步的模型名;
    • Base URL:一般不用改(已预填官方地址);
    • 备注 / 官网链接:可选;
    • 思考模式:默认关闭(响应更快);需要更强推理时可打开,但会变慢;
  7. 点 测试连通性:按钮会变成”测试中…”,成功后显示”连接成功 + 响应 X.Xs”;
  8. 关闭设置窗口即自动保存——不用找保存按钮。

[图片说明:此位置为模型设置页,操作为填写 API Key 与模型 ID 后点击测试连通性]

平台列表里已经有:阿里云百炼、OpenAI、DeepSeek、智谱 GLM、月之暗面 Kimi、Ollama(本地)。也支持”+ 自定义平台”。

安全提示:Key 只保存在本机 config.json(已加入 .gitignore,不会随代码上传)。请不要把 config.json 发给别人。

11. 端侧模型:离线使用与三档选择

“端侧”就是”模型跑在你自己的电脑上”:完全离线、不消耗额度,适合不想花钱或网络受限的情况。

11.1 什么时候会提示下载?

当你把「识别」或「翻译」开关从云端切到本地时,如果本地还没有模型,程序会弹出一个档位选择面板,列出每档的体积、速度、准确度、代价,你选好再点下载。下载过程中右下角会显示进度条;下载完成后会自动切到端侧。

11.2 三档怎么选?

识别(OCR)三档:

档位 体积 速度 适用
轻量 16MB 最快(约 0.8 秒/张) 清晰印刷体够用
均衡(默认) 120MB 较快(约 6 秒/张) 长文本、密排、表格更稳
全量 196MB 较慢(约 4-5 秒/张) 小字、模糊、复杂版式最准

翻译三档:

档位 体积 速度 覆盖
轻量 79MB / 语言对 每段 0.03-0.1 秒 仅英↔中/日/韩/法/德/俄/西/葡/意/阿/泰/越
均衡 约 2.4GB 每段约 3-4 秒 一个模型覆盖 200 种语言
全量 约 5.2GB 每段约 2-10 秒 200 种语言,质量最高

注意:端侧翻译的均衡/全量是多语言单模型——换语言不用重新下载;而轻量档每换一对语言就要再下 79MB。
另外,大模型还需要”推理运行时”,程序会在同一面板里提示下载(轻量档约 62MB;均衡/全量档约 2.5GB,只需一次)。

11.3 下载源选哪个?

面板里有「模型下载源」开关:

  • 自动:先连官方,失败自动换镜像(默认);
  • 官方:只连 HuggingFace 官方;
  • hf-mirror:只连国内镜像,国内网络建议选它。

如果下载卡住或报错,先切到 hf-mirror 再重试。

11.4 管理已下载的模型

设置 → 翻译设置 → 端侧模型管理:

  • 查看每档的状态与占用空间;
  • 随时切换档位(切换后生效,旧档可保留也可删除);
  • 删除不再需要的档位以释放磁盘。

11.5 完全离线的用法

  1. 识别开关切到「本地」,按提示下载 OCR 模型;
  2. 翻译开关切到「本地」,选择档位并下载翻译模型;
  3. 之后不需要联网、不需要 API Key,截图 → 识别 → 翻译全在本机完成。

12. 设置页逐项说明

设置窗口左侧有六个分页:

模型设置 — 平台管理(已配置/未配置分区、悬停删除、自定义平台)+ 具体设置(名称、连通性测试、备注、官网、API Key、模型 ID、Base URL、思考模式、JSON 请求预览与模板编辑)。

常规设置

  • AI 设置:是否启用云端 OCR(云端/本地)、模型最长响应时间(默认 180 秒)、失败自动尝试次数(默认 3 次)、图片压缩上限(默认 2048 像素长边);
  • 保存设置:应用缓存位置、题目保存位置、AI 回答自动加入本地知识库;
  • 行为与快捷键:默认提问、四个全局快捷键均可修改;
  • 提示词设置:OCR 提示词、回答提示词(回答提示词支持 {question} {ocr_text} {qtype} {qtitle} {options} 占位符)。

翻译设置

  • 翻译方式:云端 / 端侧;端侧引擎选择;
  • 默认语言方向、默认展示方式(双语对照 / 仅译文);
  • 端侧模型管理(见第 11 章):三档状态、下载、删除、下载源;
  • 自动刷新开关与间隔;
  • 提问与提示词:示例提问(每行一条)、默认提问、已记住的提问(可清空)、翻译提示词。

外观主题

  • 5 套预设:浅色 / 深色 / 灰色 / 护眼 / 高对比,点击即全局生效;
  • 自定义配色:底色、面板、卡片、内嵌区、正文、次要文字、边框、主色、主色文字、成功/警告/错误;
  • 形态与细节:圆角大小、界面字号、洞口边框颜色与样式、面板不透明度;
  • 支持导出/导入主题 JSON。

识别历史 — 最近 100 条识别结果,可查看、复制、清空。

关于应用 — 版本信息、请求记录(最近 20 周灰→绿方格图)、GitHub 仓库、QQ 交流群、开源许可证。

13. 常见问题 FAQ(新手最可能遇到的 20 个问题)

Q1:状态栏一直显示”未配置 API Key”怎么办?
A:打开设置 → 模型设置 → 选中你要用的平台 → 填 API Key 与模型 ID → 关闭窗口即自动保存。或改用端侧模型(识别与翻译都切到本地),这样不需要 Key。

Q2:提示”接口返回 401/403”?
A:Key 无效、平台未开通该模型,或模型 ID 写错。请核对 Key 与模型 ID,并用「测试连通性」快速排查。

Q3:提示”接口返回 404”或”模型不存在”?
A:多数是模型 ID 填错(例如把显示名当成 ID)。请到平台控制台复制准确的模型 ID。

Q4:识别很慢或一直”处理中”?
A:① 换更快的小模型;② 关闭”思考模式”;③ 把图片压缩上限调小(设置 → 常规设置);④ 改用端侧轻量档 OCR。

Q5:点了”复制”但粘贴出来还是旧内容(甚至是一张图)?
A:v2.4.0 已修复:复制统一由程序写入系统剪贴板。若你用的是旧版本,请升级。复制成功时右下角会弹出”已复制”提示;若提示”复制失败”,说明系统剪贴板被其他程序占用,稍后再试。

Q6:洞口里面点不动、也不能拖动窗口?
A:这是故意设计的——洞内鼠标穿透,方便你点后方的网页/题目。移动窗口请拖顶部图标栏或底部状态栏。

Q7:窗口边缘能拖动改变大小吗?
A:可以,拖四边或四角都行。但注意:悬浮窗太小会自动变成迷你条,迷你条拖宽会自动变回悬浮窗。

Q8:迷你条太窄/太小看不清?
A:把迷你条向右拖宽(超过 560)它会自动变回悬浮窗;也可以在迷你条的提问行里直接输入问题,点识别图标复用上次选区。

Q9:第一次切到”本地”时弹出下载提示,能不下吗?
A:可以点”暂不”,此时不会切换;等你需要离线时再点一次开关,它会再次提示。想省空间就先用云端。

Q10:端侧模型下载很慢或失败?
A:① 把下载源切到 hf-mirror 再重试;② 检查磁盘剩余空间(翻译全量档需要约 8GB);③ 网络不稳定时可在网络空闲时重试,已下载的部分会保留。

Q11:本地 OCR 报错”模型未安装/未下载”?
A:打开设置 → 翻译设置 → 端侧模型管理,在”识别模型”里下载任意一档(轻量档 16MB 即可)。

Q12:端侧翻译的译文看起来很奇怪?
A:轻量档(opus-mt)能力有限,只适合”看懂大意”;想要质量请切云端,或下载均衡/全量档(官方 NLLB 模型,质量明显更好)。这也是为什么程序在端侧翻译面板里明确标注了准确度提示。

Q13:翻译出来带着 --- 或者提示词?
A:v2.4.0 已修复(翻译提示词改为 JSON 数组进出,并过滤分隔符与提示词残留)。请升级到最新版。

Q14:框选后翻译模式右边是空的?
A:v2.4.0 已修复(结果事件会丢失的问题——现在窗口会主动回拉最近一次结果)。请升级到最新版。

Q15:翻译方向不对(比如中译英却译成中译中)?
A:检查翻译模式顶部的 [来源] ⇄ [目标] 是否选对;选”自动检测”时,极短文本可能判断不准,建议手动指定来源语言。

Q16:屏幕是 125%/150% 缩放,识别区域会偏吗?
A:不会,程序已做 DPI 适配,支持多显示器和不同缩放。

Q17:编辑 config.json 后设置被覆盖了?
A:请在退出程序后再编辑配置文件,否则退出时程序会写回内存里的配置。

Q18:打包版把文件放哪了?
A:配置在 exe 同目录的 config.json,模型在 exe 同目录的 models\,历史在 history.json。整个文件夹拷走就能在新电脑上继续用。

Q19:能在多台电脑同时用吗?
A:可以,但注意 API Key 是共享额度;也可以各自配置自己的 Key。

Q20:会收集我的数据吗?
A:不会。截图只发送给你自己配置的 AI 平台(云端模式时);端侧模式全程不联网;所有配置与历史只存在你本机。

14. 性能、体积与资源占用

项目 数值
安装包(exe) 约 288MB(不含任何端侧模型)
端侧 OCR 模型 轻量 16MB / 均衡 120MB / 全量 196MB
端侧翻译模型 轻量 79MB(每语言对)/ 均衡约 2.4GB / 全量约 5.2GB
端侧推理运行时 轻量档约 62MB;官方大模型约 2.5GB(均只需一次)
内存占用 云端模式约 500MB-1GB;端侧均衡档约 3GB;端侧全量档约 6GB
端口 / 联网 不监听端口;云端模式仅访问你配置的 API 平台

选择建议:

  • 只用云端 → 完全不用下载端侧模型,总计约 288MB;
  • 需要离线识别 → 下载 OCR 轻量或均衡档(16-120MB);
  • 需要离线翻译 → 加下翻译轻量档(79MB/语言对)或均衡档(2.4GB)。

15. 更新、备份与卸载

更新

  • 打包版:到 Releases 下载新 exe 覆盖旧文件,config.json 与 models\ 都保留,配置不丢;
  • 源码版:git pull 后重新 pip install -r requirements.txt;若改动过界面,再执行一次 npm run build。

备份

  • 备份 config.json(含你的 Key 与全部设置)、models\(已下载的端侧模型)、history.json(识别历史)。

卸载

  • 打包版:删除 exe 及其同目录的 config.json、models\、cache\、questions\、history.json、request_log.json 即可,无注册表残留;
  • 源码版:删除项目文件夹与 .venv。

名词 通俗解释
OCR “光学字符识别”,就是把图片里的文字变成可复制文本的技术
API / API Key API 是”程序之间对话的接口”;API Key 是你调用 AI 平台的”钥匙”,相当于账号密码,要保密
模型 / 模型 ID 模型是 AI 的”大脑”;模型 ID 是它在平台上的准确名字(填错就用不了)

知识库(本地) 你自己维护的”常见题→答案”对照表,命中后直接返回,不调用 AI

绿色版 / 免安装 不用安装、不写注册表,删掉文件夹就卸载干净
hf-mirror HuggingFace 的国内镜像站,下载模型更快(程序里可一键切换)
