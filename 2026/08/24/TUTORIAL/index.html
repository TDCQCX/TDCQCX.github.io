OCR 助手 — 从零开始的新手使用教程

1. 这个软件是做什么的

OCR 助手 是一款 Windows 桌面工具:屏幕上悬浮一个”透明窗口”,窗口中间有一个透明的洞口。把洞口对准屏幕上的任意内容(题目、文档、网页、代码…),一键完成三件事:

  • 示例场景 1:线上答题。把洞口对准题目,点击”截图并识别”,AI 直接给出答案。
  • 示例场景 2:看图文资料。对准一段英文/图片文字,自动转成可读文本并总结。
  • 示例场景 3:本地文档。无需联网也能识别文字(切换到本地 OCR 模式)。

它会记住你的设置,支持多套 AI 平台、双 OCR 引擎、多主题外观,完全本地保存配置,不上传任何隐私。

2. 核心功能一览

功能 说明
透明洞口悬浮窗 仅洞口透看目标,其余不透明;可拖动、可缩放,尺寸自动记忆
双 OCR 模式 云端(大模型识别,精度高)/ 本地(RapidOCR,离线免费)
多 AI 平台 阿里云百炼、OpenAI、DeepSeek、智谱GLM、Kimi、Ollama,支持自定义
图文答题 图片+文字同时发给模型,可关思考模式提速
本地知识库 常见题关键词命中即秒回,不消耗 API
JSON 请求模板 底层请求可完全自定义,实时预览
多主题 黑 / 白 / 灰 + 图片背景
全局快捷键 Ctrl+F1 识别、Ctrl+Q 退出

3. 准备工作:两种使用方式怎么选

方式 适合人群 需要装 Python? 难度
打包版 exe 绝大多数新手 不需要 ★
源码运行 想研究代码 / 二次开发 需要 ★★★
  • 只是想用这个软件 → 直接看 第 4 章。
  • 想从源码跑起来、改代码 → 看 第 5 章。

系统要求(两种方式相同):

  • Windows 10 / 11(64 位)
  • 屏幕无特殊限制,支持多显示器与 100%/125%/150%/200% 缩放
  • 网络:使用云端模式需要能访问你选择的 AI 平台 API;本地 OCR 模式可完全离线

6. 快速上手:完成第一次识别

⚠️ 第一次使用请先按 第 7 章 配置好 AI 平台(填 API Key),否则会提示”Key 未配置”。

6.1 认识主窗口

主窗口分上中下三部分:

  • 上部:蓝色圆角标题”OCR 助手”、提问输入框、置顶/配置/主题/退出按钮。
  • 中部:红色边框的透明洞口——对准这里。
  • 下部:「截图并识别」等按钮 + 状态,以及可折叠的【识别结果】【回答】区块。

[图片说明:此位置为主窗口整体截图,操作为指出上中下三块区域与红色洞口]

6.2 对准目标区域

  1. 按住上部设置区或下部空白处拖动窗口,让洞口套住目标内容。
  2. 拖动窗口边缘/角落可缩放洞口大小,程序会自动记住窗口尺寸。

[图片说明:此位置为窗口对准某道题目的场景,操作为拖动悬浮窗使题目完整处于红色洞口内]

6.3 填写提问(可选)

顶部”提问/指令”默认是 “请给出该题目的答案”;识别网页、总结文档时可改成你自己的问题,例如”翻译这段文字”。

6.4 开始识别

点击 「截图并识别」 或按全局快捷键 Ctrl+F1:

  1. 程序瞬间隐藏红色边框并截图(约 0.06 秒,保证截图干净);
  2. 云端/本地 OCR 识别洞口内的文字;
  3. 解析题型/题目/选项;
  4. 交给大模型图文理解并回答。

结果会分区块显示:

[图片说明:此位置为识别完成后的界面,操作为展示【识别结果】与【回答】两个区块,按钮行显示”题型·来源·OCR耗时·回答耗时”]

  • 点击区块标题可折叠/展开,折叠后窗口高度自动跟随,洞口大小不变。

6.5 常用操作

操作 方法
复制回答 点击「复制结果」
清空结果 点击「清空」
再次识别 重新对准后按 Ctrl+F1
退出 Ctrl+Q

7. 配置:让程序认识你的 AI 平台

点击顶部 「配置」 打开设置窗口。左侧是导航(模型设置 / 常规设置 / 关于应用),选中项为浅蓝高亮。

7.1 模型设置(必做)

模型设置页采用 左中右 布局:

中部 —— AI平台管理

预置了 6 家主流平台:

平台 默认官网 默认 Base URL(请求地址)
阿里云百炼 bailian.console.aliyun.com https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions
OpenAI platform.openai.com https://api.openai.com/v1
DeepSeek platform.deepseek.com https://api.deepseek.com/v1
智谱 GLM open.bigmodel.cn https://open.bigmodel.cn/api/paas/v4
月之暗面 Kimi platform.moonshot.cn https://api.moonshot.cn/v1
Ollama(本地) ollama.com http://localhost:11434/v1
  • 已配置(填了 API Key)的平台显示正常色,排在上方;未配置的平台以暗色虚化排在下部;
  • 鼠标悬浮某平台卡片,右侧会出现 ×,点击可删除该平台;
  • 点击 「+ 自定义平台」 可添加你自己的平台(名称可点击编辑,需自行填写模型ID 与请求地址)。

[图片说明:此位置为模型设置页,操作为展示中部平台列表(已配置/未配置分区)与右侧设置表单]

右侧 —— 具体设置区

  1. 在平台列表中选中你要用的平台;
  2. 点击 「测试连通性」 按钮前的 logo 名称旁(名称可点击修改),随后依次填写:
字段 必填 说明
API Key 是 各平台控制台申请的密钥(输入框内眼睛图标可切换明文/密文)
模型ID 是 例如百炼可填 qwen3.7-flash-2026-07-15、OpenAI 可填 gpt-4o-mini
Base URL 否 上表默认值一般无需修改
官网链接 否 便于一键跳转申请密钥
备注 否 自由备注
是否开启思考 否 关闭=响应快(默认);开启=推理更强但更慢
  1. 填写完成后点击 「测试连通性」:按钮初始为绿色,点击后变灰”测试中…”,成功变绿并显示”响应 X.Xs”,失败变红”测试失败”。

[图片说明:此位置为测试连通性按钮三种状态,操作为点击后按钮由绿→灰→绿并左侧显示响应耗时]

  1. 窗口下方是 JSON 请求预览,会随你的填写实时生成将要发送的请求体(无需手动修改;想改底层模板点”编辑模板”)。

💡 关闭设置窗口即自动保存,无需找保存按钮。

7.2 常规设置

保存设置

  • 应用缓存位置 / 题目保存位置:默认在程序目录下(cache/、questions/),可点”浏览”改到其他位置;
  • 勾选”将 AI 回答自动添加到本地知识库”后,识别过的题目会自动入库,下次同题直接秒回。

AI设置

  • 是否启用云端OCR:右侧”云端 / 本地”二选一。
    • 云端:用你选的平台大模型识别文字,精度高但消耗 token;
    • 本地:内置 RapidOCR,离线免费、轻量快速(约 50MB,CPU 约 100-300ms)。
  • 模型最长响应时间:默认 180 秒;
  • 失败自动尝试次数:默认 3 次(网络错误会自动重试)。

[图片说明:此位置为常规设置页,操作为指出”云端/本地”互斥按钮与下方小字说明]

提示词设置

  • OCR 提示词与回答提示词均可自定义;回答提示词支持占位符 {question}/{ocr_text}/{qtype}/{qtitle}/{options}。

8. 进阶:直接编辑 config.json

想手动改配置时,可直接编辑配置文件(源码运行时在项目根目录;打包版在 exe 同目录)。编辑前请先退出程序,否则退出时会被覆盖。

主要分组:

分组 作用
active_provider / providers 当前平台 ID 与各平台完整配置(含 API Key)
prompts OCR 提示词与回答提示词
request_template 请求体 JSON 模板(占位符 {model}/{prompt}/{image_url})
window 置顶、窗口尺寸、圆角、洞口边框色
theme 主题预设与图片背景
capture 截图压缩上限、瞬隐时长
timeout / retry 最长响应时间、失败重试
ocr.mode cloud(云端)/ local(本地)
knowledge 本地知识库条目
hotkeys 全局快捷键
behavior 默认提问
app 关于页信息

9. 常见问题 FAQ

Q1:状态栏一直显示”Key 未配置”?

A:进入「配置 → 模型设置」,选中你的平台并填写 API Key 后关闭窗口即可;也可直接编辑 config.json 中该平台的 api_key。

Q2:点击识别提示”接口返回 401/403”?

A:API Key 无效、平台未开通该模型或请求地址错误。核对 Key 与模型ID,可用”测试连通性”按钮快速排查。

Q3:本地 OCR 报错”模型未安装”?

A:源码运行请执行 python -m pip install rapidocr_onnxruntime;打包版则下载完整版 exe。

Q4:识别慢怎么办?

A:① 关闭思考模式(模型设置 → 是否开启思考取消勾选);② 切换到本地 OCR;③ 减小洞口范围。

Q5:屏幕是 125%/150% 缩放,截图会偏吗?

A:不会。程序已做 Per-Monitor V2 DPI 感知,支持多显示器与不同缩放。

Q6:想换一个 AI 平台?

A:「配置 → 模型设置」中部列表选择其他平台,填写对应 API Key/模型ID 即可,互不影响。

Q7:数据安全吗?

A:API Key 仅保存在本地 config.json(已加入 .gitignore,不会随代码上传);图片只发送给你选择的 AI 平台用于识别。

10. 更新与卸载

更新

  • 打包版:去 GitHub Releases 下载新版本 exe 覆盖旧文件即可,配置(同目录 config.json)不受影响;
  • 源码版:git pull 拉取最新代码后,重跑 pip install -r requirements.txt。

卸载

  • 打包版:直接删除 exe 及其同目录生成的 config.json、cache/、questions/、request_log.json 即可(无注册表残留);
  • 源码版:删除项目文件夹与虚拟环境 .venv 即可。
