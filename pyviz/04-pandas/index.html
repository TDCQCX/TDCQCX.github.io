本章难度：⭐⭐⭐ | 预计学习时间：15 小时 | 前置章节：03 NumPy
这是整门课最重要的一章。 学完它，你以后 80% 的数据处理工作都是它。

学习目标

学完本章你能做到：

  1. 看懂 Series 和 DataFrame 到底是什么，知道它们和 Excel 表格的对应关系；
  2. 从 CSV 把数据读进来，把处理结果存出去；
  3. 用布尔索引、query、loc、iloc 精确取出你要的行和列；
  4. 用 groupby + agg 做任意口径的分组统计（这是数据分析的核心动作）；
  5. 用 merge、concat、pivot_table 把多张表拼起来、转成需要的形状；
  6. 用 .dt、.str 访问器处理日期和文本；
  7. 把一段处理流程写成可读的链式调用，并知道什么时候该用 apply、什么时候必须用向量化；
  8. 认识 pandas 3.0 与老教材的差异，不踩过时的坑。

4.0 先搞清楚：Pandas 是什么

一句话：Pandas 是 Python 里用来处理表格数据的库。
它的核心是两种数据结构：

结构 中文 类比 说明
Series 序列 Excel 里的一列 一维，带行标签（索引）
DataFrame 数据框 Excel 里的一张表 二维，有行标签和列名

为什么不用 Excel？ 三个理由，都很实际：

  1. 数据量：Excel 一张表最多 104 万行，再大就打不开了。pandas 处理几百万行是日常。
  2. 可复现：Excel 里点几十次鼠标做的处理，下周你完全想不起来步骤。
    代码写下来，永远能重跑，改一个参数就能换口径。
  3. 可组合：pandas 处理完的数据能直接喂给 scikit-learn 建模、喂给 matplotlib 画图，
    是一条完整流水线。Excel 做不到。

为什么又要先学 NumPy？ 因为 DataFrame 的每一列底层就是一个 NumPy 数组。
第 3 章的广播、向量化、np.where 这些概念，在 pandas 里天天用到。

4.1.2 数据类型（dtype）速查

dtype 含义 例子
int64 整数 数量

4.3 取数：行、列、单元格

这是 pandas 用得最多、也最容易搞混的部分。我用一张表先讲清楚”括号里放什么、取到什么”，
然后逐个给例子。

写法 取到什么 返回类型
df["城市"] 一列 Series
df[["城市", "销售额"]] 多列 DataFrame
df[df["销售额"] > 5000] 符合条件的行 DataFrame
df.loc[标签, 列名] 按名字取 看情况
df.iloc[位置, 位置] 按位置编号取 看情况
df.at[标签, 列名] 单个单元格（按名字） 标量
df.iat[位置, 位置] 单个单元格（按位置） 标量

核心记忆点：

  • 一个方括号 df[...] 里放列名→取列；放布尔条件→取行。不能放行名。
  • 想同时指定行列，用 .loc（按名字）或 .iloc（按位置），格式是 [行, 列]。

⚠️ loc 和 iloc 最坑的区别：loc 的切片是”含结尾”的，iloc 是”不含结尾”的。

  • df.loc[0:3] → 第 0、1、2、3 行（4 行）
  • df.iloc[0:3] → 第 0、1、2 行（3 行）

记忆方法：iloc 的 i 可以想成”index 那种 Python 风格”，和列表切片一致。

⚠️ 常见报错：KeyError: 0
原因：用了 iloc 却传了列名，或者用了 loc 却传了位置编号。
解决：看清行列是”名字”还是”编号”。比如 df.loc[0, 3] 会报错，
因为 0 是索引标签没问题，但 3 不是列名。要写 df.iloc[0, 3] 或
df.loc[0, "省份区域"]。

  3. 真需要 apply 时，优先 apply 到列（axis=0，默认）而不是行（axis=1），
